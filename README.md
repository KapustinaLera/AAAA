Трекер отказа от курения и алкоголя
Целевая аудитория: люди, которым необходим контроль над вредными привычками

Сущности: User (имя, дата рождения, пол, дата начала отказа, тип зависимости (курение/алкоголь/оба), ежедневный бюджет для расчёта экономии, целевое количество дней), DayRecord (дата, уровень тяги (1–10), количество выкуренного/выпитого, самочувствие (1–10), настроение, качество сна, физическая активность (была/нет), заметки, фото «до/после»), HealthMilestone (количество дней без привычки, описание пользы, иконка), Achievement (тип достижения (например, «7 дней»), дата получения).
Экраны: главный (статистика: сколько дней держится, экономия денег и польза здоровью), добавление записи (выбор уровня тяги, количества), график прогресса.
Сеть: запрос мотивирующих цитат и отображение их на главном экране.
Уведомления: ежедневное напоминание «Не сдавайся! Держишься N дней».
Медиа: возможность прикрепить фото «до/после» к записи.
Анимация: анимированный индикатор прогресса (кольцо) при добавлении записи и в статистике.
